# AGENTS.md

## Project
`verifier_experiments/` is a self-contained cost/quality benchmark for an OpenAI-based
**IPhO-mechanics solution verifier** (spec: `verifier_experiments/CLOUD_AGENT_SPEC.md`,
correctness definition: `verifier_experiments/DEFINITION.MD`). It builds a labeled
fault-injection dataset, runs 9 verifier configs (3 levers × V0–V2) + a composed system,
and reports per-problem cost reduction and quality parity. See
`verifier_experiments/README.md` for the full command sequence and layout, and
`verifier_experiments/REPORT.md` for results.

## Cursor Cloud specific instructions

- **Python venv lives at repo root `/.venv`** (not inside `verifier_experiments/`). Always
  `source .venv/bin/activate` first. The venv needs the system package `python3.12-venv`,
  and PDF extraction needs `poppler-utils` (`pdftotext`, `pdftoppm`) — both are apt
  packages, not pip, so they are NOT in the update script; install them with apt if a
  fresh VM lacks them (`sudo apt-get install -y python3.12-venv poppler-utils`).
- **Run everything as a module from inside `verifier_experiments/`** (e.g.
  `python -m bench.run`, `python -m bench.report`), because the packages `verifier` and
  `bench` are imported by name and there is no installed package / `sys.path` shim.
- **OpenAI key:** the only secret required is `OPENAI_API_KEY` (already read by the SDK).
  No other provider is used.
- **Budget guardrail is real and cumulative.** Every LLM call goes through
  `verifier/common/client.py`, which prices actual usage and **aborts at $8/run**
  (`--hard-cap`). The cap resets per process, so when running multiple passes pass
  `--prior-spend <running_total>` to keep the cumulative spend under $10. Reconstruct the
  true running total any time by summing `cost_usd` across `runs/*.jsonl`.
- **Prefer concurrency + phased runs.** `gpt-5` with reasoning is slow (~15–20 s/call);
  run with `--workers 6`. The strong-model V0 baselines (`A.V0`,`B.V0`,`C.V0`) dominate
  cost/time — run them at low reps (N=2) and the cheap configs at N=3. A full sweep is
  ~900 calls and ~$5–7.
- **Do not pipe long runs through `tail`/`head`** — it buffers until completion and hides
  progress. Monitor by reading `results/raw_results.jsonl` (flushed per row) or
  `results/*.log`.
- **`runs/` and `results/` are gitignored** (raw logs); summary tables/plots are
  force-added for traceability. Regenerate them with `python -m bench.build_dataset`
  (deterministic), then `tune` → `run` → `report` → `make_deck`.
- **The deck** (`presentation/DECK.pdf`) is generated by `bench/make_deck.py` (reportlab,
  pure-Python — no browser/LibreOffice needed) and reuses the exact plots in
  `presentation/assets/`.
